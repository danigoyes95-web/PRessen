# Algo Sano – Mini juego

Come sano, esquiva la grasa y no revientes.

## Publicar en GitHub Pages
1. Crea un repositorio y sube `index.html`.
2. Settings → Pages → Source: rama `main`, carpeta `/ (root)`.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Controles
Dedo, mouse o flechas / A-D. Espacio o Enter para empezar.
